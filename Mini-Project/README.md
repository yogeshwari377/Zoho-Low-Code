# Student Feedback Management System

### A Low-Code Application Developed Using Zoho Creator

## 📌 Project Overview

The Student Feedback Management System is a low-code web application developed using **Zoho Creator** to simplify the collection, management, and analysis of academic feedback in educational institutions.

The system provides a centralized platform for managing student details, course information, feedback responses, and semester-wise performance summaries.

## 🎯 Objectives

- Digitize the student feedback collection process.
- Reduce manual data entry and administrative effort.
- Validate student feedback ratings.
- Generate structured feedback reports.
- Visualize course evaluation results through dashboards.
- Automate repetitive operations using Deluge scripting and workflows.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Zoho Creator | Low-code application development |
| Deluge Scripting | Validation and automation |
| Zoho Creator Database | Data management |
| Zoho Creator Reports | Feedback reporting |
| Zoho Creator Page Builder | Dashboard development |
| Zoho Creator Workflows | Process automation |

## 📂 Application Modules

The application consists of four primary modules:

1. **Student** – Maintains student information.
2. **Course** – Stores academic course details.
3. **Feedback Response** – Collects student evaluations and suggestions.
4. **Semester Summary** – Organizes semester-wise feedback information.

## ✨ Key Features

- Student and course management
- Feedback submission and rating validation
- Lookup relationships between forms
- Automated student email population
- Feedback reports and dashboard analytics
- Scheduled semester summary workflow
- Blueprint-based process management
- Role-based access design

## 📊 Feedback Evaluation Criteria

Students can evaluate courses based on:

- Content Quality
- Delivery
- Clarity
- Engagement
- Overall Satisfaction
- Suggestions
